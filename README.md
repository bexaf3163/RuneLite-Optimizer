# RuneLite Optimizer 0.5.0 (test release)

Независимая portable-программа для проверки плавности RuneLite и настройки Standard GPU / 117 HD. Репозиторий и запуск OSRS Path не меняются.

## Три режима без обязательного замера

На странице «Автоподбор» есть три кнопки стартовых настроек для ранее обнаруженного ПК: Intel i5-1135G7, Iris Xe, 16 ГБ памяти. Это рекомендации по характеристикам и назначению параметров, а не результаты игровых бенчмарков. Стабильные 60+ FPS до замеров не подтверждены.

- **Стандартная:** отключаются GPU и 117 HD; графические плагины не используются. Предел программного рендерера около 50 FPS, поэтому 60+ в этом режиме не обещаются.
- **GPU:** дальность 40, загрузка карты +1, MSAA 2×, фильтрация 4×, Unlock FPS включён, VSync выключен, лимит 72 FPS. 117 HD отключается.
- **117 HD:** дальность 30, детали 25, загрузка карты +1, разрешение 100%, без MSAA, фильтрация 4×. Быстрые тени 1024 с лёгкой фильтрацией; текстуры, normal mapping и немного источников света сохранены. POM, расширенные/ландшафтные тени и прозрачность теней выключены. Лимит 72 FPS; GPU отключается.

Глобальный лимит FPS Control отключается во всех трёх режимах. Остальные плагины и настройки доступности/цветов не меняются. Параметры, отсутствующие в установленной версии плагина, пропускаются. 117 HD должен быть установлен через Plugin Hub; оптимизатор не скачивает произвольный код плагинов самостоятельно.

Сначала выберите установленный/распакованный OSRS Path EXE и запустите клиент кнопкой оптимизатора, чтобы загрузился отдельный модуль. После обновления оптимизатора старый запущенный клиент нужно перезапустить из новой версии: используется протокол 2. Далее выберите режим и подтвердите план. Программа попросит закрыть RuneLite, дождётся отсутствия клиентов и Java-процессов, применит настройки и запустит клиент снова. Быстрое применение не требует ETW или игрового замера и помечается как «без замеров». Принудительное закрытие игры, вход, перемещения, камера и телепорты не автоматизируются.

## Автоподбор по замерам

Отдельная кнопка запускает поиск качества в выбранном режиме. Исходная графика сравнивается с четырьмя упорядоченными профилями: высокое качество, баланс, плавность, минимальная нагрузка. Проверяются дальность, MSAA, загрузка карты, фильтрация; в HD дополнительно тени, освещение, POM, текстуры и масштаб разрешения. Лестница не перебирает все комбинации всех параметров; это ограниченный поиск, а не доказательство глобального оптимума.

Каждый проход включает Lumbridge, Varrock, Grand Exchange и Falador: 30 секунд стоять, 30 секунд вращать камеру и 60 секунд идти. Прибытие, поворот камеры, пройденное расстояние, мир, размер игровой области и фокус окна проверяются автоматически. После каждого полного прохода программа просит закрыть клиент и автоматически применяет следующий профиль и перезапускает игру. Всего до 6 проходов / 48 минут кадров плюс переходы и прогрев.

Первый прошедший уровень качества повторно проверяется с лимитом 72 FPS. Во всех 12 сценах/фазах нужны средний FPS не ниже 72 (65 в финале), 1% low не ниже 60, p99 не выше 16,67 мс и отсутствие интервалов длиннее 33,33 мс. Слишком отличающееся число игроков не позволяет считать проход сопоставимым. Если ни один уровень не прошёл, повторно проверяется профиль с лучшими измеренными худшими показателями; неуспех обозначается явно. Итог не гарантирует отсутствие будущих зависаний от подгрузки, драйвера, фоновых программ или другой нагрузки.

## Независимость и возврат настроек

OSRS Path не редактируется, не пересобирается и не заменяется. Используется его существующий модуль запуска без изменения исходников/ASAR. Собственный Java-модуль оптимизатора читает необходимые условия теста; отдельный оверлей не перехватывает ввод. Совместимость загрузки модуля установленной распакованной сборки проверена отдельно без запуска игры. Полный живой проход и перезапуск с изменённой графикой пока не выполнены.

Автоматические записи выполняются только в определённый модулем активный файл `.runelite/profiles2/*.properties` после закрытия клиента. Путь хранится в зашифрованном локальном состоянии, не включается в отчёты. Исходные значения и незавершённая транзакция защищены Windows DPAPI; полные копии файла также зашифрованы. Не относящиеся к плану настройки сохраняются. Смена файла/профиля, ручное изменение управляемых параметров и перенаправления пути блокируют запись. Cloud sync RuneLite может вернуть удалённые настройки при запуске — в этом случае ожидаемый профиль не считается подтверждённым.

Кнопка «Остановить / вернуть графику» работает и после перезапуска оптимизатора: закройте игру, дождитесь возврата исходных параметров. Незавершённое восстановление не разрешает начать другой подбор. По завершении можно оставить подобранные настройки; исходная копия остаётся доступной. Служебные файлы: `%LOCALAPPDATA%\RuneLiteOptimizer`, отчёты: подпапка `Guided\Reports`. Отчёты не содержат игровых аккаунтов, полного конфигурационного файла или его приватного пути.

## Запуск

Скачайте **RuneLite-Optimizer.exe** из Releases и запустите. Архив, установщик и соседние файлы не нужны. Нужны Windows 10/11 x64 и .NET Framework 4.8. Все компоненты и документация встроены в EXE. Сам EXE можно переименовать и держать в удобной папке.

При начале измерения встроенный PresentMon извлекается с проверкой SHA-256 в `%LOCALAPPDATA%\RuneLiteOptimizer\Runtime`. Это служебный кэш, не отдельный установщик. Справочник HD читается из ресурсов EXE. Руководство, план оптимизации и лицензии открываются на странице «Обновления».

## Автообновления

При запуске автоматически проверяется последний стабильный выпуск **bexaf3163/RuneLite-Optimizer** на GitHub. Новая версия загружается в фоне; проверяются точный адрес выпуска/имя EXE, размер, SHA-256 из GitHub API и версия файла. Понижение версии и предварительные выпуски исключены.

Когда файл готов, нажмите «Установить и перезапустить». Это завершит текущий замер, поэтому сначала сохраните отчёт. Игра не закрывается. Отдельная копия помощника ждёт завершения оптимизатора и атомарно заменяет его EXE по исходному пути. Если файл изменился после запуска помощника, замена запрещена. При непосредственной ошибке запуска новой версии восстанавливается прежняя. Аварийное завершение уже запустившейся новой версии не определяется как ошибка установки.

Проверку и загрузку можно отключить на странице «Обновления»; ручная проверка остаётся доступной. Нет соединения — текущая версия продолжает работать, причина доступна там же. Кэш/настройка обновлений: `%LOCALAPPDATA%\RuneLiteOptimizer\Updates`. Хэши подтверждают соответствие файлу официального GitHub-выпуска; EXE пока не имеет отдельной подписи издателя.

Старые версии 0.1/0.2 ещё не содержат обновлятор: новый EXE нужно скачать один раз вручную. Последующие версии будут предлагаться в программе.

Для оборудования и настроек администратор не нужен. **Измерение кадров через Windows ETW требует членства в Performance Log Users либо ручного запуска от администратора.** Программа не повышает права и не меняет группы автоматически. При отказе доступа показывается причина; выдуманных FPS нет.

## Измерение сеанса

- Обнаруживает запущенный RuneLite и подключается к его PID. Игра запускается привычным способом, в том числе через OSRS Path. Если клиентов несколько, выберите нужный.
- Официальный PresentMon 2.6.0; SHA-256 проверяется при подготовке сборки и исполнении. Нет внедрения DLL или модификации клиента.
- Средний FPS = число кадров / сумма интервалов. 1% low = 1000 / среднее худшего 1% интервалов. Также p50/p95/p99, доля интервалов в бюджете 16,667 мс, количества интервалов >33,333 / >50 / >100 мс.
- График последних 15 секунд сохраняет максимумы при объединении кадров в пиксели. Выше 250 мс график визуально ограничен, но сами интервалы полностью остаются в статистике.
- Живые карточки показывают последние 30 секунд, чтобы редкие старые события не скрывали текущие изменения и полный сеанс не пересортировывался каждую секунду. Сравнение и экспорт используют весь выбранный проход.
- Swap chains анализируются отдельно. По умолчанию выбирается поток с наибольшим числом кадров; это эвристика, а не доказательство принадлежности игровому viewport. Можно выбрать поток вручную в параметрах сбора.
- По умолчанию исключает фон. Фокус опрашивается каждые 100 мс и сопоставляется с QPC временем всего интервала кадра. Более короткие переключения между опросами могут быть пропущены.
- Grand Exchange, Varrock, Falador, Lumbridge и другое место выбираются **вручную**. Координаты и населённость мира не считываются. Флажок теста без лимита — отметка пользователя, он сам не изменяет клиент.
- Стоп отключает автоподключение. Новый процесс игры начинает новый сеанс. При отказе ETW на одном PID бесконечных повторных попыток нет.
- Для каждого сравниваемого прохода нужно минимум 120 секунд кадров. Сравнение проверяет отмеченную сцену, режим лимита и фильтр фокуса. Мир, ракурс, размер окна и число игроков сверяются вручную.
- Экспортируется локальный текстовый отчёт. Сырые настройки, аккаунты, командные строки и игровые логи не экспортируются. Кадры и базовый проход хранятся в памяти до выхода; отчёт нужно сохранить. После 1 млн кадров накопление прекращается с предупреждением.

PresentMon поддерживает анализ OpenGL, но доступность нужного потока зависит от драйвера и способа представления. Интервалы приложения **не гарантируют частоту показа монитором**, не являются временем GPU или сетевым ping. Если событий нет, нельзя делать вывод о FPS. Пауза без событий отмечается как отсутствие данных, а не 0 FPS. Завершившееся зависание остаётся длинным интервалом.

## Профили

| Параметр | Стабильные 60 | Тест запаса |
|---|---:|---:|
| Unlock FPS | true | true |
| VSync | OFF | OFF |
| FPS target | 60 | 999 |
| Draw distance | 25 | 25 |
| Extended map loading | 0 | 0 |
| Anti-aliasing | DISABLED | DISABLED |
| Anisotropic filtering | 1 | 1 |
| HD detail distance | 25 | 25 |
| HD shadow mode | OFF | OFF |
| HD scene resolution | 100% | 100% |

999 — высокий тестовый предел, не обещанные FPS и не бесконечный лимит. После теста верните 60. FPS Control, VSync драйвера и другие лимитеры проверяются отдельно. Игровые тики не ускоряются.

117 HD устанавливается в **RuneLite → Plugin Hub → 117 HD**. Оптимизатор не устанавливает/не включает плагины автоматически. Запись hd.* не доказывает, что HD установлен и активен. Сохраняйте привычный способ запуска игры.

## Все настройки HD

Раскройте «Все параметры 117 HD / поиск»: **100 видимых** настроек из официального исходника `04fd8520a3db9e8c196e987d7164ff9e6c2c701c`, включая окружение, свет, текстуры, legacy и experimental. Скрытые внутренние/миграционные поля исключены. Названия/пояснения плагина пока на английском.

Откройте активный .properties; двойной щелчок добавляет изменение в отдельный план. Bool, enum и числовые границы проверяются по скомпилированной схеме. Нажмите «Применить выбранные HD-параметры», проверьте список и подтвердите. Быстрый профиль меняет только поля таблицы выше. Экспериментальные настройки меняйте отдельно с повторным замером. Набор полей установленной версии HD может отличаться.

## Сохранность

Выберите .properties **активного** профиля вручную, проверьте предпросмотр, закройте RuneLite и Java-приложения, подтвердите запись. Создаётся DPAPI-копия для текущего пользователя Windows; чужие байты сохраняются. При изменении файла после предпросмотра запись отменяется. Сложный синтаксис properties отклоняется.

Резервные копии: `%LOCALAPPDATA%\RuneLiteOptimizer\Backups`. Откат запрещён, если текущий файл изменился после применения. Во время игры запись/откат запрещены. После запуска проверьте значения в плагине: облачная синхронизация RuneLite может вернуть свои настройки.

Другие плагины, OSRS Path, службы, реестр, драйверы, сеть и приоритеты не меняются. Температура, GPU load, VRAM и точная причина задержек не измеряются. Устойчивые 60 FPS не гарантируются.

## Сборка и проверки

```
./tools/prepare.ps1
./test.ps1
```

prepare скачивает фиксированный официальный PresentMon и проверяет SHA-256. Сборка — системным .NET Framework compiler, без SDK/NuGet. Node нужен только для сопровождения: `node tools/update-hd-catalog.mjs` обновляет с закреплённого исходника схему и каталог.

Тесты проверяют фиктивные конфигурации, откат/конфликты, CSV/QPC, точные метрики, длинные интервалы, фокус и все 100 HD-полей. UI проверяется сверху/снизу и с раскрытым каталогом при 1120×840 и 800×660. Это **не заменяет живую проверку RuneLite**.
