# RuneLite Optimizer

Отдельная переносимая Windows-программа для диагностики и настройки производительности RuneLite. Версия 0.1.0. Не зависит от OSRS Path и не меняет его репозиторий.

## Запуск

Скачайте portable-архив из раздела **Releases**, распакуйте и запустите `RuneLite-Optimizer.exe`. Требуется Windows 10/11 с .NET Framework 4.8 (обычно уже установлен). Установка и права администратора не нужны.

## Что работает

- Диагностика CPU, памяти и видеокарты, версии драйвера при доступном WMI.
- Снимок памяти/CPU обнаруженных процессов RuneLite. Недоступные показатели явно обозначаются.
- Три профиля **стандартного GPU plugin**: плавность 60 FPS, баланс 90 FPS, экономия 30 FPS.
- Просмотр семи конкретных изменений перед записью в **вручную выбранный** локальный файл `.properties`.
- Зашифрованная Windows DPAPI резервная копия и откат с защитой от затирания новых изменений.
- Локальный текстовый отчёт и ручное сравнение введённых результатов FPS до/после.

## Применение профиля

1. Проведите диагностику. Включите Draw FPS в RuneLite и измерьте одну сцену до изменения.
2. Вкладка «Настройки GPU»: выберите профиль и локальный `.properties` активного профиля RuneLite. Программа не угадывает активный аккаунтный профиль. Обычно файлы находятся в `%USERPROFILE%\.runelite` и его подкаталогах.
3. Проверьте план. Закройте RuneLite и другие Java-приложения. Нажмите «Применить к файлу» и подтвердите.
4. Запустите RuneLite привычным способом — через OSRS Path, если он нужен вашему плагину. Проверьте GPU-настройки в клиенте: синхронизация аккаунта может вернуть другие значения.
5. Повторите тот же замер. На вкладке «До / после» сравните средний FPS, измеренный одинаковым способом.

При работающем RuneLite или Java автоматическая запись/откат запрещены. Сложный синтаксис properties отклоняется; используйте памятку для ручного применения. Резервные копии находятся в `%LOCALAPPDATA%\RuneLiteOptimizer\Backups`, зашифрованы для текущего Windows-пользователя. Не переносите их на другой аккаунт. Откат работает только если текущий файл полностью совпадает с результатом применения: иначе он откажется затирать более новые настройки.

## Ограничения первой версии

Это не автоматический измеритель FPS/frametime или обещание прироста. Без внутриигровой телеметрии программа не определяет FPS, 1% lows, температуры, загрузку GPU, VRAM, поддержку OpenGL или точную причину лагов. Показатели CPU/памяти сами по себе не доказывают bottleneck. FPS после профиля необходимо измерять.

Профили не включают GPU plugin и не выключают другие плагины. Они **не применимы к 117 HD**: его графические параметры настраиваются в самом HD. FPS Control может дополнительно ограничивать FPS. Снятие лимита камеры не ускоряет игровые тики/сеть. Реестр, службы, сетевые параметры, драйверы, приоритеты процессов и настройки OSRS Path не меняются. Нет телеметрии/отправки конфигурации в интернет.

Windows UI проверяется отдельно от headless-тестов. Первые профили — разумные стартовые варианты, а не аппаратно доказанные лучшие настройки для каждого ПК.

## Сборка и проверки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

Компилятор .NET Framework из Windows; NuGet/Node/Python не требуются. Автотесты используют синтетические конфигурации, а не реальные настройки пользователя. GitHub Actions собирает и проверяет код; успешная сборка main публикует portable-релиз по VERSION, только если такой релиз ещё не существует. Для нового релиза обновите VERSION и версию в приложении; уже опубликованные архивы не перезаписываются.
